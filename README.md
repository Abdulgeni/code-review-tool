# AI Code Review Tool

Paste any code — get instant AI review for bugs, logic errors, edge cases, and best practices. Built with Next.js and Google Gemini AI.

## Live Demo

[code-review-tool.vercel.app](code-review-tool-mu.vercel.app)

## Features

- Paste code in any language
- AI analyzes for bugs, security issues, edge cases
- Structured review report
- Sample code for quick testing
- Fallback review when AI is unavailable
- Supports JavaScript, Python, TypeScript, Java, C++, Ruby, Go, Rust

## Tech Stack

Next.js | TypeScript | Tailwind CSS | Gemini 2.5 Flash | Vercel

## Quick Start

```bash
git clone https://github.com/Abdulgeni/code-review-tool.git
